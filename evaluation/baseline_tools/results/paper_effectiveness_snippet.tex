\textbf{Benchmarks.}
We evaluate \name with three open-source microservice applications: Bookinfo (6 services), an Istio demo with moderate routing and canary policies; Online Boutique (11 services), an e-commerce application with richer traffic-management configurations; and Sock Shop (13 services), a retail application with diverse resilience and access-control settings. These applications comprise more than 30 microservices in total. For scalability experiments, we further generate synthetic service-mesh deployments with configurable policies and dependencies.

\textbf{Baselines.}
We compare \name against:
\texttt{istioctl analyze}~\cite{istioctl-analyze}, Istio's production static analyzer;
Kyverno~\cite{kyverno}, a Kubernetes-native policy engine evaluated with a small Istio-oriented policy set;
\texttt{kube-linter}~\cite{kubelinter}, a general Kubernetes best-practice linter;
and PolicyLite~\cite{gatekeeper}, a lightweight admission-style rule set in the spirit of OPA Gatekeeper (weight-sum, ALLOW+DENY conflicts, STRICT vs.\ DISABLE mTLS).
We further include Static Only and Dyn.\ Only ablations of \name, and report the complete Hybrid workflow.

This experiment evaluates whether \name can detect cross-layer semantic inconsistencies, and how it compares with existing validators and single-modality ablations.

To evaluate effectiveness, we compare \texttt{istioctl analyze}, Kyverno, \texttt{kube-linter}, PolicyLite, Static Only and Dyn.\ Only ablations of \name, and the complete hybrid workflow on ten representative misconfigurations (routing, traffic splitting, mTLS, authorization, timeout, retry, and circuit breaking), each applied to a live Bookinfo deployment under Istio.
Table~\ref{tab:hybrid-effectiveness} summarizes the results.
External tools provide only partial coverage.
The two ablations are complementary---Static Only is strong on declarative cross-resource inconsistencies, while Dyn.\ Only recovers runtime-exposed deviations---yet neither alone covers the full suite.
By fusing static cross-resource reasoning with policy-aware runtime validation, Hybrid \name detects all ten cases.
