# ConfigPilot 方案实现状态

更新日期：2026-11-17。以代码入口和测试为准；正式实验支持范围与工程能力分别记录。

## 已实现功能

| 功能 | 实现方式 | 验证入口 |
|---|---|---|
| 统一语义模型 | 策略节点显式输出 `paoc`，保留字段来源和版本 | `test_new_architecture` |
| 公共语义边界 | HTTP 语义位于 parser 模型层，静态与动态共同消费，不反向解析 | 验证规划回归 |
| 依赖热点与 Go | 索引化闭包缓存；serial/thread/process 与可选 Go 正式接口 | 固定点差分、完整计划对照、Go 测试 |
| 统一验证工作流 | `configpilot/workflow.py`；统一命令和 `/api/validation/` | CLI、冻结回放、Web API 测试 |
| 通用受控执行 | 支持普通 HTTP 和分流；保留明确的 /2 参数契约 | 通用 HTTP、重试/连接池及分流回归 |
| 任务并发 | 请求级闭合契约下共享读取；实际池状态继续互斥 | 同 VS 并发峰值与逐义务判定 |
| 总负载准入 | 配置、状态和 `load:N` 原子预留，受 `--capacity` 限制 | 容量和锁原子性测试 |
| 共享采集 | 多任务 ID 批量读取、共享快照及完成时间新鲜度约束 | 查询计数、快照复用和并发回归 |
| 记录生命周期 | 数量上限、完成记录 TTL、显式回收、过载标记 | 容量、回收与活跃记录保留测试 |
| 证据持久化与中断 | 逐探针原子落盘后释放记录，失败时恢复已完成证据 | 持久化/回收顺序与部分完成测试 |
| 多次运行隔离 | 同主机入口/后端文件租约，重叠运行拒绝 | 租约互斥与释放 |
| 外部配置变更检查 | 可选只读 UID/RV/spec 执行前后快照；变化时结果未判定 | 配置变化失效与回放测试 |
| 全部义务报告 | 三值结果、计划覆盖和实际完成度分开；完整性复核 | 分母保留、缺证据和错误目标测试 |
| 配置/策略/证据图 | 依赖图、证据引用、失败候选和潜在服务影响 | 失败诊断、图与 API 读取 |
| 双向有效行为检查 | 对已投影模型从两侧生成有限见证，检查有效行为差异 | 实际侧新增路由、顺序改变、不可达冗余回归 |

## 部分实现与待支持功能

| 内容 | 状态 | 仍缺什么、当前如何处理 |
|---|---|---|
| 完整跨层语义等价 | 部分 | 缺少完整原生 Envoy 关系投影与全域判定；有限比较始终不宣称等价已证明 |
| 任意作用域、继承和多资源优先级 | 部分 | 保留关系及未解析原因；没有经过解释的组合不获得复用/执行许可 |
| 生产 Envoy/Prometheus/OTel 请求级适配 | 部分 | 原生遥测采集器保留；共享采集覆盖受控回执，不假设 Header 已进入所有遥测 |
| 异常实例摘除及恢复 | 未支持 | 需要真实多 Endpoint 身份、摘除状态与恢复证据；不把连接池 UO 当作实例摘除 |
| 限流、mTLS、授权、镜像和 gRPC 的专属 oracle | 部分/未支持 | 原协议/配置解析能力保留，但没有统一套用受控 HTTP 判定；无充分证据时保留未知 |
| 自动容量发现与自适应负载 | 未支持 | 当前只执行明确预算，不自动猜测安全吞吐或熔断阈值 |
| 集群范围分布式资源调度 | 未支持 | 文件租约仅协调同主机协作进程；其他主机和集群外部更新需要进一步机制 |
| 全部原生遥测事件通知 | 部分 | 已有单调时间唤醒和 worker 让出；不声称所有观测源实现推送事件 |
| 证据依赖图前端与报告统一展示 | 部分 | 数据与 API 已提供；保留原三层图/SQLite 页面，不宣称完成专用界面 |
| 根因因果推断和 Top-k 准确率保证 | 未支持 | 当前是依赖距离候选，应另做带已知根因的诊断评估 |
| 任意策略组合的无损正交 | 不作此保证 | 使用受支持规则的完整组合准入和有限缺陷回归，不用两两兼容推出任意组合 |

这些项需要不同的运行证据、语义解释或环境条件，不能用删除义务、放开状态锁或宽松 PASS 来代替实现。

## 测试与复现

```bash
python -m unittest discover -s istio_Dynamic_Test/tests -v
```

核心测试：`test_relational_workflow.py` 与 `test_new_architecture.py`。可选 Go 测试需先构建并设置 `CONFIGPILOT_TEST_GO_BINARY`。本地 HTTP 测试代理只验证适配器和工作流，不等同于真实 Envoy 行为实验。

2026-11-16 的 Windows 与 Linux 回归均通过 98 项测试（包括 Go 路径）；独立命名空间中的真实 Envoy 冒烟覆盖健康、错误重试和错误连接池三种场景，独立/复用规划逐义务结果一致。探针数 11→4，客户端请求数 26→19，义务分母保持 11。配置版本检查、证据回收、测试环境删除及业务 VS/DR 不变均已核对。实验产物在本地单独保存，不随源码发布。

机器清单由 `python -m configpilot capabilities` 或 `GET /api/validation/capabilities` 提供。历史实验数据保留原目录；不同实现与测量口径的性能比需要分别报告。
